## Scope across files and archives

Licensing follows the material, including copies inside ZIP and tar archives. Extracting a file or copying it to another directory does not change its licence.

| Material | Licence |
| --- | --- |
| Program source, test implementations and executable code examples | MIT |
| JSON schema definitions and software execution configuration, including dependency lists and Git configuration | MIT |
| Explanatory prose, study documentation, captions and other textual reports | CC BY 4.0 |
| ODG drawings, SVG vector sources, PNG previews and their scientific source data | CC BY 4.0 |
| Synthetic input dossiers, scientific parameter values, expected outcomes, computational results, certificates, logs and evidence inventories | CC BY 4.0 |
| Source code reproduced within a report or retained evidence container | MIT for the code; CC BY 4.0 for the surrounding report and data |

In particular, `.py` files and `.schema.json` definitions use MIT. Scientific inputs and outputs in JSON, CSV and other formats use CC BY 4.0. A JSON document does not become software configuration merely because a program reads it.

These grants apply to the rights held or controlled by the project rightsholder. Separately identified third-party material retains its own terms. Licence texts and notices are retained in their supplied form. External runtimes and installed dependencies are not included in the grants for project material.
