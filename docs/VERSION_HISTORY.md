# Version history

## 1.0.0

First standalone distribution of the verification and reference-audit companion.

The distribution derives from the qualified internal software baseline `5.0.0-local.3`. The new public version sequence starts at 1.0.0. Algorithm and historical-result identities are retained separately from distribution metadata.

Packaging changes establish the standalone citation metadata, concise Markdown documentation, a documented projection of the retained input capsule and regenerated current inventories. The integration runner binds that capsule by its path and SHA-256. The custody command reports technical integrity separately from the licence terms.

The component versions, frozen profile identifiers, experimental locks and historical run labels retain their own meanings.
