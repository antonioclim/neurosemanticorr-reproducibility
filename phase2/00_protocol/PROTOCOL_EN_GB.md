# Local Phase 2 evaluation protocol

## Question and scope

Does an executable O15 reference distinguish declared semantic conventions on a new discriminating dossier, retain correct direct-pointer behaviour on independent controls and report that a common-convention model is incompatible with a synthetic transcript? The unit is a dossier containing the documentary records R15 claims, R15 edges and R11 result. This protocol qualifies the O15 reference and the decision procedure. New probes do not enter the archived performance denominators. The archived software verifiers are neither the implementation under test nor the adjudicators of the new probes.

The policy list and order are `literal_only`, `suffix_only`, `either_unique`, `prefer_literal` and `prefer_suffix`. Only lookup of an `alias:` key varies. The policies use the literal token, the suffix, a unique location across available spellings, literal before suffix or suffix before literal, respectively. A selected target must be a direct pointer. The common reference checks result identity, exact value and the pointer's unit, denominator and scope. It preserves the frozen violation-over-missing precedence. Direct pointer token decoding and array index syntax follow RFC 6901 sections 3 and 4. The local contract restricts a source pointer to a nonempty string starting with `/`. RFC 6901 establishes pointer resolution. The documentary metadata or result identity establishes the additional claim relation under O15.

## Locked comparisons and acceptance

1. The synthetic dual-conflict pair changes which of two different targets matches the claim. A suffix-target claim should separate `either_unique` from `prefer_suffix`. The literal-direction matched control should reject under both. The complete normative matrix in `01_fixtures/EXPECTED.json` is locked independently of the evaluation. Report every policy, label and trace. The fixture author does not execute the new evaluator before the lock. These are designed cases by a separate contributor to the same project.
2. Direct-pointer controls check the expected outcome for all five hypotheses. Positive and negative controls include escaping, the distinction between an object key and an invalid array index with a leading zero and an equal-valued target under incompatible metadata. Missing documentary evidence is an adjudicated `U` where the contract specifies it. A missing adjudication is omitted from the transcript rather than recorded as `U`.
3. The synthetic transcript uses local policy authorities simulated by the fixture design. If observed labels are compatible separately but incompatible with all declared global policies, report `OUT_OF_MODEL` and no numeric interval. Check each local authority separately and test that the apparent result cannot be a false `AT_OR_BELOW` decision. An empty version space refutes the declared model relative to this transcript. Cause attribution requires separate evidence.
4. Repeat the five reference projections on the archived 192 cases for custody and calibration. Exact reproduction covers signed labels under `either_unique`, recorded paired outcomes and Phase 1 counts. Keep the illustrative threshold `H ≤ 24` from Phase 1. Compute the sharp conditional range and the exact minimum-cardinality query set over the frozen frame. Compare with an exhaustive finite check of coverage; the result remains a retrospective analysis. The witness chooses what to adjudicate. It cannot by itself supply the authoritative label.

The protocol, cases, normative predictions, code and relevant original hashes are locked locally before the first integrated evaluation. The pre-execution lock supplies local chronology and a reproducible binding, without external registration. Pass requires exact equality with the independent fixture predictions and no changes to the archived inputs. Disagreement with a prediction remains visible in the receipt. No frequency of real-world failures or performance on the new probes of any archived checker is estimated here.
